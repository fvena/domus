# Lo que un módulo aporta a Kira

Un módulo aporta a Kira, en su carpeta `assistant/`, una skill (`SKILL.md`), frases rápidas y avisos para la iniciativa. Es solo texto y descripciones, nunca código de negocio: Kira actúa llamando a acciones por la API. No fija la forma del agent, que se decide en la fase 5.

Fecha: 2026-11-11. Preguntas del grilling: P31.
