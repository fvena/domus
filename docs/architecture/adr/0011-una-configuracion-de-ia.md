# Una sola configuración de IA

Hay una sola configuración de IA para todo Domus. Las llamadas sueltas usan AI SDK Core, y un runtime propio del agent tiene dos adapters: el Claude Agent SDK con la suscripción y AI SDK Core para los modelos por API. La forma del agent se decide en la fase 5.
