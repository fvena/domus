# Fechas dichas con palabras

Las fechas dichas con palabras las interpreta el modelo y la API las valida; no hay intérprete de lenguaje propio. Las frases rápidas solo entienden «hoy», «mañana» y los días de la semana. Si algún día hace falta más, se usa una librería, no código propio.
